# Štěnice
Na koleji 17. listopadu jsou štěnice. Pojďme sledovat jejich šíření v čase.

Data pocházejí z neoficiálních zdrojů a mohou být zastaralá. Zveřejněné pozice pokojů s výskytem štěnic mohou být lehce posunuty pro znemožnění identifikace.

Předpokládáme výšku schodu přesně 17cm (odchylka ± 1cm) a výšku budov zaokrouhlenou na 62m a 52m. Tloušťku pokoje 3.75m, což při počtu 8, resp. 12 místností dává délku budovy 30m, resp. 45m. Šířka obou budov je 23m. Obdélník mezi budovami je přibližně 20m×26m.
